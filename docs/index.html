Features

📋

Clipboard History

Automatically saves everything you copy, up to 200 items. Deduplicates entries and keeps the most recent.

🔍

Quick Search

Instantly filter your clipboard history with a built-in search bar.

💾

Persistent Storage

History is saved to disk and survives app restarts and system reboots.

🚀

Launch at Login

Start automatically when you log in. Toggle it on or off from Settings.

⚡

Lightweight & Fast

Single-file Swift app with minimal resource usage. Lives in your menu bar.

🔒

Privacy First

All data stored locally. No network requests, no analytics, no telemetry.

Install

# Clone and build
git clone https://github.com/flaviomuniz/clipboard-history
cd ClipboardHistory
./build.sh

# Install to Applications
cp -r ClipboardHistory.app /Applications/
